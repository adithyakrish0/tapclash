# 🎯 Tap Clash

A Telegram Mini Game where you tap as fast as you can in 10 seconds and challenge your friends to beat your score!

## Features

- ⚡ 10-second tap challenge
- 🏆 Global leaderboard
- 🔥 Challenge friends with shareable links
- 📱 Telegram Mini App (no download needed)
- 🛡️ Anti-cheat protection
- 🎨 Beautiful, modern UI
- 💰 Free to build and deploy

## Tech Stack

| Component | Technology |
|-----------|------------|
| Frontend | React + Vite |
| Backend | Node.js + Express |
| Database | SQLite |
| Hosting | Vercel (frontend) + Railway (backend) |
| Platform | Telegram Mini App |

## Quick Start

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## How It Works

1. User opens bot in Telegram
2. Clicks "Play Now"
3. Taps the button as many times as possible in 10 seconds
4. Score is saved to leaderboard
5. User can challenge friends by sharing a link
6. Friends click the link and try to beat the score
7. Viral loop continues!

## Monetization Options

- **Adsgram**: Show ads in the mini app
- **Telegram Stars**: Sell power-ups and extra lives
- **Affiliate Links**: Promote exam platforms
- **Premium Features**: Exclusive game modes
